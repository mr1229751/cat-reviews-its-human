This entry is a one-star review written by a cat about its human, 115 characters in total. The grievance is a closed bathroom door. The cat demands that it be opened, wins the argument, and then walks away, because access was always a matter of principle rather than need.

The program in `main.ts` stores that review as a constant, checks it against the competition gate before writing anything, and then saves it as `entry.txt` inside the directory named by `MAKEFUN_OUTPUT_DIR`. The check enforces the full gate: between 1 and 200 characters, exactly one line, and never blank whitespace. Only Node built-ins are used, and there is no randomness, so repeated runs produce the exact same file.

The line itself survived a comparison against six alternatives. It won for its flat review format, its escalating pettiness, and a final sentence that reframes the whole complaint as a point of honour.

## Running the entry

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
