One one-star review, 115 characters, written by a house cat about its human: the bathroom door was closed, entry was demanded, entry was refused — the point was the principle. A tiny Node program writes that single line to the entry file, guarding the gate itself: 1–200 characters, one line, never only whitespace. The line was picked by criteria critique over six rivals for its deadpan review shape and its sting in the final sentence.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
